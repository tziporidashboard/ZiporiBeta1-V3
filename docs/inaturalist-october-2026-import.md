## מימוש ובדיקות

המקור החדש הוא `public/inaturalist-october-2026-additions.json` (schema 2).
הוא נוסף אחרי כל המקורות הקיימים באמצעות `appendInaturalistAdditions`.
schema 1 של ספטמבר נשמר. מזהה קיים לעולם אינו נדרס; טעינה חוזרת אינה
מוסיפה כפילויות. חבילה עם מזהים כפולים, תאריך לא מאומת, שדות לא תקינים
או סתירה בפרטיות נדחית. הקישור הראשי מוביל לתצפית המקורית ב־iNaturalist.

שדה `excel_row` הקיים משמש ב־schema 2 כמספר הרשומה הלוגית ב־CSV,
כולל שורת הכותרת; `sheet_name` ריק. משמעות זו רשומה בחבילה. המטא־דאטה
כוללת גם מזהה, UUID, טקסון ודרגה, זמן שליפה, חתימת תשובת API, ראיות
תאריך ופרטיות וחתימת יומן התיקון.

לשחזור/אימות ללא כתיבה:

```text
python scripts/prepare-inaturalist-october.py PATH_TO_ADDITIVE_AUDIT
npm run test:october
npm run test:import
npm run test:merlin
npx tsc --noEmit
npm run build
```

`--write` לסקריפט כותב רק את חבילת התוספת. ברירת המחדל דורשת זהות
בתים לחבילה הקיימת. מקורות הנתונים והתיקון אינם נכתבים. חבילת התוספת:
`b367c3fd3c6efc48100efd039fdffe23f2595539bd5194004c196f79795b2c28`.

הבדיקות מכסות את כל הרצף ההיסטורי, מניעת כפילויות, זמן חסר, שדות המקור,
שיוכים, מנגנוני נדירים/פולשים, כל חמשת צרכני המסננים, מפות, מונים,
סדרות זמן וייצוא בשתי שפות. התנהגות ההשוואה הקיימת נשמרה: גרף ההשוואה
וטבלת המדדים מציגים את כל קבוצות המשתמשים, ובלשונית אנשים יש בורר
קבוצות מקומי. בדיקת הארכיון של MERLIN ממשיכה להצמיד את חתימת קוד
ספטמבר לאותו Git blob היסטורי; התנהגות הטוען הנוכחי נבדקת בנפרד.

תוצאות לפני פרסום לפיתוח: 118 בדיקות עברו, ללא כישלונות או דילוגים;
TypeScript ו־Build עם `VERCEL=1` עברו. בדפדפן מקומי אומתו סך 16,181,
מסנני איכות/שנה/קבוצה, איפוס, בחירת מין עם תצפית חדשה, משתמש חדש,
