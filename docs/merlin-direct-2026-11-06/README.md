## המימוש

- `src/lib/merlin-source.ts` ממיר את 22 עמודות הייצוא ישירות למבנה התצפית, כולל תאריכים ושעות, שמות, מזהים, קואורדינטות ומטא־נתוני המקור. הוא מאמת את הסכמה, 2,644 הרשומות, מזהים ייחודיים ושדות נדרשים.
- `src/lib/observations-store.tsx` מבקש רק את מקור MERLIN החדש. הוסרו מפענח 88 העמודות, לולאת הסנכרון והחזרה לקובץ ההיסטורי במקרה של כשל.
- הגבול המספרי הקבוע 114909 משמש לסדר התצוגה בלבד: הוא שומר על סדר השורות הקודם ביחס לתוספת iNaturalist, בלי לקרוא נתון מהארכיון ובלי להחליט אם תצפית תיכלל. כך גם סדר שורות הייצוא נשמר.
- סיווגי MERLIN נשארים מוגבלים לתצפית באמצעות `professional_metadata.taxonomy`, לפי המקור והמדיניות שכבר אושרה לזיהויים כלליים. לא שונה המילון המשותף או סיווג כלשהו של iNaturalist.
- שדות `iconic_taxon_name` ו־`taxon_order_name` ההיסטוריים אינם מסופקים בייצוא החדש ונשארים ריקים בתצפיות MERLIN. נבדק שאין תצוגה, מסנן, מפה או ייצוא פעיל של MERLIN שנזקק להם; הסיווג המפורש של המקור מקבל קדימות. לא הומצאו להם ערכים חלופיים.
- מנגנון הסנכרון והטוען הקודם נשמרו רק ב־`tests/fixtures` לצורכי שחזור והשוואה אוטומטית. הם אינם מיובאים בקוד האפליקציה.

## גיבוי ושחזור

הקובץ המלא הועבר מ־`public` לארכיון מקומי המוחרג במפורש באמצעות `.gitignore` ואינו נכלל ב־Commit:

`data-archive/merlin/2026-11-05/MERLIN all observations for Zohar.csv`

הארכיון מכיל 2,357 רשומות, 88 עמודות ו־2,252,206 בתים, כולל שלושת הסשנים וכל השדות ההיסטוריים. הוא זהה למקור ברמת הבתים, SHA-256:

`42438b9a029b8ba81ff8625e7a28b8863adde48a70c69b5d30d3823981de8b75`

הוראות שחזור מקומיות נמצאות לצד הגיבוי ב־`data-archive/merlin/2026-11-05/README.md`. הארכיון אינו מוגש כקובץ ציבורי של הדשבורד ואינו נוסף למאגר. דוחות הסנכרון והחריגות מ־5.11 נשמרו ללא שינוי.

בדיקות ההשוואה משתמשות בגיבוי המקומי כשקיים. בעותק Git מלא ללא הגיבוי הן קוראות את הקובץ מתוך ה־Commit הרשמי ההיסטורי `b6a19d8a80805cf81fed3ec78d8af5e177b4bca2`, משחזרות את סיומות השורה המקוריות של Windows ומאמתות את אותה חתימת SHA-256. כך הבדיקות אינן דורשות לפרסם עותק נוסף של הגיבוי. בעותק shallow נדרשת היסטוריית Git המכילה את ה־Commit הזה, או הגיבוי המקומי. מחיקת הקובץ מהענף הנוכחי אינה מוחקת אותו מהיסטוריית Git הקיימת; לא בוצע שכתוב היסטוריה.

- בעת עדכון עתידי יש לבצע השוואה לפי מזהה, לבדוק כל מזהה חסר ולקבל החלטה לגביו לפני החלפת המקור הפעיל ועדכון מספר הרשומות וחתימת המקור בקוד. טעינה ישירה אינה הרשאה למחיקת רשומות חסרות בעתיד.

### הודעות ומגבלות

לא נמצאו שגיאות טעינת נתונים, כפילויות או רגרסיה בתרחישים שנבדקו. בשרת הפיתוח נרשמו שלוש הודעות React ברמת error על העברת `key` דרך spread ל־CircleDot/CrossDot/DiamondDot. מקורן בקוד הגרף הקיים (`src/components/time-series-chart.tsx:225`), שלא שונה במשימה. לא בוצע תיקון מחוץ לתחום השינוי. בבנייה הופיעו אזהרות על חבילה גדולה מ־500KB ועל הוראות/ייבואים בספריות צד שלישי; ה־Build הסתיים בהצלחה.

השינוי מוכן לבדיקת המשתמשת ולפרסום בסביבת הפיתוח לאחר אישור נפרד. הבדיקות הממוכנות מכסות את הרשומות כולן; בדיקות הממשק הן בדיקות תרחישים ולא מעבר ידני על כל תצפית.

לא בוצעו Commit, Push או פריסה. השינוי מיועד לבדיקה מקומית ולאישור נפרד לפני פרסום.
